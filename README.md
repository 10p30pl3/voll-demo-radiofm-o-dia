# Demo — Portal FM O Dia

Portal operacional navegável com dados fictícios, referente ao projeto PV-869.

## Executar

Abra `index.html` no navegador ou publique o conteúdo deste repositório em uma hospedagem estática. Não há backend nem etapa de build.

## Telas

- Painel operacional
- Aprovação de áudios
- Ouvintes e detalhes do ouvinte
- Grade de programação
- Promoções e sorteios
- Clube FM O Dia Raiz
- Publicidade

O logotipo da FM O Dia é utilizado exclusivamente para demonstração à rádio. Consulte `LEIAME.txt`.
